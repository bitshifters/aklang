# ArchieKlang Announcetro (Acorn Archimedes)

A cheeky 28 KB intro for the Acorn Archimedes by Bitshifters, Alcatraz and Torment, released at NOVA 2024 in the Oldschool Demo Compo. It was the first production on the Archimedes to use Virgill's AmigaKlang soft synth, which generates 280+ KB of sample data from a few KB of code.

- Prod page: https://bitshifters.github.io/posts/prods/bs-archieklang.html
- Pouet: https://www.pouet.net/prod.php?which=97158
- The ArchieKlang port of AmigaKlang: https://github.com/kieranhj/archieklang

This repository is a snapshot of the source for the released build. It is cut down from the [archie-verse](https://github.com/kieranhj/archie-verse) demo framework to only the code, data and tools this production uses. The full development history is in archie-verse, at tag `archive/aklang-main`.

Some things this intro demonstrates for Archimedes demos:

- Using ArchieKlang to generate sample data at init time.
- Embedding the QTM RM into the executable.
- Use of TinyQTM (stripped down to 14 KB from 26 KB, although previously 69 KB!)
- Use of the RISC OS font library to render font glyphs that can be copied as sprites.
- Use of vlink to strip bss segments from object files.
- Use of Shrinkler to compress the 87 KB executable down to 28 KB.

## Running

The release targets ARM250 and faster machines; there is also an ARM2 version. Both run on RISC OS 3.1 with 2 MB of RAM. If you get a "No writeable memory at this address" error, reboot and try again. Under emulation use [Arculator](http://b-em.bbcmicro.com/arculator/) v2.1 or later: emulate an A3010 and set the sound output filter to "more reduced".

## Building

Builds on Windows, from cmd or Windows Terminal (not Git Bash). You need Python 3 on the PATH as `python.exe`; the PNG converter uses the copy of pypng in `bin/`. The assembler (vasm), linker (vlink), Shrinkler, SplitMod, make (`snmake.exe`) and dos2unix are in `bin/`.

| Command | Builds |
|---|---|
| `make` or `make.bat` | Release build for ARM250+: `!AKlang` with the Shrinkler-packed `!Run`, plus the Spark archive `build\bs-archieklang,ddc`. |
| `make.bat arm2` | ARM2 release build (`_SLOW_CPU=1`): `!AKlang` and `build\bs-aklang-arm2,ddc`. |
| `make.bat uncompressed` | `!AKlang` with an uncompressed `!RunImage`, started by an obey file. |
| `make.bat debug` | Uncompressed, assembled with `_DEBUG=1`. |
| `make.bat deploy` | Copies `!AKlang` to `..\arculator\hostfs\Builds`. Use `make.bat deploy HOSTFS=path` to copy somewhere else. |
| `make.bat music` | Regenerates `src\gen\arcmusic.asm` (checked in) from `data\akp\Rhino2.mod.txt`. Needs `pip install parse`. |
| `make.bat clean` | Removes `build` and `!AKlang`. |

## Layout

| Path | Contents |
|---|---|
| `archie-verse.asm` | Entry point: build options, system init, main loop. |
| `src/app.asm`, `src/fx/` | The intro: bits, outline-font scroller and scope effects. |
| `src/data/` | Sequence and scrolltext. |
| `src/gen/arcmusic.asm` | The AmigaKlang synth script for the samples, generated by `bin/akp2arc.py`. |
| `src/loader.asm` | Small loader that Shrinkler-decompresses the main binary. |
| `lib/` | The parts of the archie-verse framework library this production uses, including `archieklang.asm` and `arc-shrinkler.asm`. |
| `data/akp/` | AmigaKlang project (`Rhino2.akp`), its exported script and raw sample data. |
| `data/music/` | The MOD; `bin/SplitMod.exe` splits out its pattern data. |
| `data/riscos/` | The embedded TinyQTM module. |
